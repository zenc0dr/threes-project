# 🕉️ Threes

**Threes** — это визуальный конструктор бизнес-логики и интерфейсов, реализованный в виде плагина `Zen\Threes` для **OctoberCMS v3**. В основе лежит гибкая нодовая система: любое действие, элемент или документ описывается через абстрактные **ноды**, которые можно свободно собирать, комбинировать и связывать.

## 📌 Основные возможности

- Проектируйте приложение из логических блоков без ручного кода
- Создавайте интерфейсы, скрипты, тесты и адаптеры к API
- Ведите **живую документацию** с интерактивными элементами — ноды могут содержать текст, схемы, UI-компоненты и даже динамические виджеты
- Используйте готовую систему прав и API для совместной работы и синхронизации
- Работайте в надёжном стеке Laravel 9 + OctoberCMS v3

## 🗂️ Ключевые компоненты

### 🌲 **Tree**
Левое меню с древовидной структурой — как в Obsidian. Здесь видны только те ноды, у которых установлено свойство `tree = true`. Такие ноды могут быть вложенными и формировать собственные иерархии.
### 📄 **Schema**
Рабочая область, где раскрывается содержимое выбранной ноды: её собственный контент (`self_content`) и цепочка вложенных нод (`schema`). Каждая вложенная нода — это отдельная инструкция или элемент. Визуально это похоже на HTML, но смысл ближе к DSL.
### 📦 **Store**
Общее хранилище всех нод. В интерфейсе находится в нижней части `Ui.vue` и показывает полный список доступных блоков.

## ✨ Ведение документации

**Threes** можно использовать как полноценную систему живой документации — аналог Obsidian, но с бонусом:

✅ Страницы-документы — это обычные ноды с гибкой структурой: текст, списки, кодовые фрагменты, изображения, ссылки на другие ноды, **интерактивные элементы** (формы, виджеты) и многое другое.
✅ Все элементы можно связывать, переиспользовать и автоматически рендерить в любом месте проекта.
✅ Вся документация хранится в нодах и может быть синхронизирована через API.

## 🗃️ Как устроено хранилище

Каждая нода — это папка с уникальным идентификатором.  
Внутри — файлы полей (`name.txt`, `props.json`) и папки под-нод.

Ноды могут содержать ссылки друг на друга, формируя гибкую сеть связей.  
Все права доступа управляются через стандартные механизмы OctoberCMS.

## 🔌 API и синхронизация

У каждой ноды есть индивидуальные настройки и API.  
Ноды можно синхронизировать между разными серверами или проектами — это упрощает совместную разработку и обмен шаблонами.

## 📖 Начало работы

1. Создайте ноды через интерфейс или API.
2. Настройте дерево `Tree` для навигации.
3. Определите структуру `Schema` для каждой ноды.
4. Используйте `Store` для поиска и управления всеми блоками.
5. Ведите документацию, добавляя к нодам тексты, ссылки и интерактивные элементы.

### Корневые файлы Threes
Файлы Threes находятся по адресу `plugins/zen/threes/` все дальнейшие внутренние пути формируются на основании этого

2. `init.php` - Инициализатор: Регистрирует функции-хелперы (на данный момент она одна `ths()->`)
3. `package.json` - Файл, содержащий метаданные, включая зависимости и скрипты для системы сборки
4. `package-lock.json`-  Файл, фиксирующий точные версии зависимостей для системы сборки
5. `Plugin.php`  - Основной файл плагина в OctoberCMS, содержащий его метаданные, регистрацию компонентов и обработку событий
6. `plugin.yaml` - Файл конфигурации плагина в OctoberCMS, содержащий метаданные, такие как название, описание, автор и зависимости
7. `readme.md` - Этот файл
8. `routes.php` - Маршрутизация
9. `Threes.php` - Родительский класс Threes
10. `webpack.mix.js` - Файл сборки Laravel mix

### ths() Хелпер
Инициация плагина начинается с файла `plugins/zen/threes/init.php` в котором объявляется хелпер `Ths`
```php
if (!function_exists('ths')) {  
    function ths(): \Zen\Threes\Threes
    {
        return \Zen\Threes\Threes::getInstance();
    }
}
```
>С этого момента, в системе доступен хелпер `ths()`

За хелпер `ths()` отвечает класс `Zen\Threes\Threes` который наследуется от класса `Zen\Threes\classes\Helpers`

### Базовые нюансы которые нужно знать при разработке новых типов
###### 1. Конфигурация типа нода
Для того чтобы появился новый тип нод нужно создать вот такой файл `storage/threes/types/Threes.NodeText.json`.  Определить  хранилище можно в переменной окружения `TYPES_STORAGE` по умолчанию это `storage/threes/types`.
Имя типа состоит из двух фрагментов `{ИмяАвтора}.{ИмяТипа}.json`
```json
{  
    "class": "Zen.Threes.Nodes.NodeText.NodeText",  
    "files": [  
        "plugins/zen/threes/nodes/NodeText/NodeText.php",  
        "plugins/zen/threes/nodes/NodeText/NodeText.vue"  
    ],  
    "store": {  
        "group": "Документы",  
        "author": "Alex Blaze",  
        "tags": ["text", "document"],  
        "created_at": "2025-06-09 13:15"  
    }  
}
```

`class` - Класс типа нода указанный в формате dot notation
`files` - Файлы необходимые для работы нода
`store` - Узел магазина
	`group` - Группа нод
	`author` - Автор
	`tags` - Тэги
	`created_at` - Создано

###### 2. Необходимые методы класса типа нода
```php
<?php  
  
namespace Zen\Threes\Nodes\NodeText;  
  
use Zen\Threes\Models\Node;  
  
class NodeText  
{  
    private Node $node;  
    private mixed $data;  
  
    public function __construct($data = null)  
    {  
        if ($data) { // Вот такие данные будут входить в класс.
            $this->node = $data['node'];  
            $this->data = $data['data'];  
        }  
    }  
  
    public function template(): array  
    {  
        return [  
            'icon' => base_path('plugins/zen/threes/src/images/icons/document.svg'),  
            'name' => "Новый документ",  
            'data' => 'Привет мир!',  
            'props' => [  
                'self_content' => true,  
                'show_children' => true,  
                'tree' => true,  
                'schema' => true,  
                'store' => false,  
                'store_data' => [  
                    'group' => 'Документы',  
                    'author' => 'Threes',  
                    'tags' => ["text", "document"],  
                    'created_at' => now()->toDateTimeString(),  
                ]  
            ]  
        ];  
    }  
  
    public function component()  
    {  
  
    }  
  
    public function getSelfContent(): array  
    {  
        return $this->getSchema();  
    }  
  
    public function setSelfContent()  
    {  
        return $this->data;  
    }  
  
    public function getSchema(): array  
    {  
        return [  
            'component' => 'NodeText',  
            'data' => $this->data,  
        ];  
    }  
  
    public function setSchema()  
    {  
        return $this->data;  
    }  
}
```
